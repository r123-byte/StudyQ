What is an .ics file or link?
An .ics file is a standard calendar file. Schools share one via Magister, Somtoday or Zermelo — download it and upload it here. A webcal:// link is a live subscription: paste it once and any new test your school adds will appear automatically in Apple Calendar, Google Calendar or Outlook.
